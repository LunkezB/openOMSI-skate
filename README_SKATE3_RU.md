# openOMSI × Skate 3

Экспериментальная интеграция внутри одного процесса openOMSI: автобус,
карта и скейтер используют одно окно. Подключена настоящая библиотека
`skate-host` из Rust-переписывания Skate 3 через MW2 mashup.

**Это экспериментальный прототип; игровой запуск проверен на Windows и Grundorf.**
Проверены переход автобус → скейт, разгон с клавиатуры и возврат за руль.
Также пройдены 8 тестов и проверка настоящей Skate-сессии с разгоном и прыжком.
[Подробности проверок](docs/SKATE3-VALIDATION.md).

Для сборки нужны актуальный Rust stable MSVC, Visual Studio C++ Build Tools,
Windows SDK и нативный Windows CMake:

```powershell
cargo build --locked --release -p omsi-app --features skate3 --bin openomsi
```

Для запуска нужны твоя установка OMSI 2, файлы Xbox 360-версии Skate 3 и
Xbox/XInput-контроллер либо клавиатура. Подготовка Skate 3, параметры запуска и ограничения:
[инструкция](docs/SKATE3.md).

В настройках openOMSI включи **Ability to get up**. На остановленном автобусе
**J** запускает выход и переход на скейт; **J** ещё раз возвращает пеший режим.
Возле водительского места **G** возвращает управление автобусом.
Также можно выбрать **Back to my bus** в меню Escape.

На клавиатуре: **W/Space** — толкаться, **A/D** — поворачивать, **S** — тормозить,
**стрелки** — Flick-It; для олли нажми вниз, затем быстро вверх.
**Q/E** — захваты, **Shift** — толчок другой ногой.

Подключены коллизии загруженных участков, поиск граней для гриндов, позы
скейтера/доски и камера. Пока нет отдельного Skate HUD, звука, синхронизации
скейта по сети и полноценного взаимодействия с движущимися платформами.

Готовую публичную интеграцию именно с openOMSI в поиске не нашёл. Близкие
реализации: [MW2 mashup](https://github.com/chasmlol/2010-rust-rewrite-mashup)
и [SkateGM](https://github.com/the-schwilliam/SkateGM).
Источники и точные версии перечислены в [NOTICE](vendor/skate/NOTICE.md).
